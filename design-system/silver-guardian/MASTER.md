# Silver Guardian Design System

The authoritative Android design specification is [UI_DESIGN_SYSTEM.md](../../docs/UI_DESIGN_SYSTEM.md).

## Master direction

- Visual language: Calm Companion / 静谧陪伴.
- Product surface: native Android, elder-friendly healthcare assistant.
- Palette: mist white, jade green, dark botanical text, restrained warm coral.
- Accessibility: 48dp minimum touch targets, 17sp body text, explicit text labels for status, 4.5:1 minimum body-text contrast.
- Hierarchy: use whitespace, typography, grouped lists, and dividers before adding shadows or additional cards.
- Assets: use the generated elder companion and AI mascot illustrations; never substitute Emoji for product icons.

Page-specific overrides in `pages/` may refine this master only when a documented product need requires it.
