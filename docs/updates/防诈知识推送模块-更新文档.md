## 二、当前数据流

```
权威内容来源（公安部/反诈中心/12321/辟谣平台/金融监管总局）
      ↓ 人工整理为统一 JSON
自建服务器 JSON 接口 ← TODO: 替换 URL
      ↓ OkHttp GET 请求
FraudApiClient.parseFraudResponse()   ──── JSON 解析失败 ──→ 使用本地 SQLite 兜底
      ↓ 成功
FraudFragment.fetchRemote()
      ↓
RecyclerView 列表展示（标题 + 分类 + 摘要 + 离线标记）
      ↓ 点击条目
FraudDetailActivity 详情展示（5 区块）

--- 后台推送 ---
WorkManager 周期任务（每 24h）
      ↓
FraudReminderWorker.doWork()
      ↓ 同步拉取远程 JSON
      ├── 成功 → 选第一条远程内容
      └── 失败 → 按日期轮换本地预置内容
      ↓
FraudNotificationHelper.sendFraudNotification()
      ↓ 用户点击通知
FraudDetailActivity
```

## 四、数据模型变更

### FraudTip（旧 → 新）

```
旧字段                    新字段
───────────────────      ───────────────────
id (int, DB 自增)  →      dbId (int, 保留)
                          id (String, 远程唯一标识)
title                     title
category                  category
content             →     detail (案例详情)
action              →     advice (防范措施)
                  新增 →  summary (一句话摘要)
                  新增 →  risk (风险说明)
                  新增 →  sourceName (内容来源)
                  新增 →  sourceType (official/local)
                  新增 →  sourceDate (来源日期)
content, action 保留为兼容字段（指向 detail/advice）
```

### JSON 格式（新版）

```json
{
  "version": 2,
  "updatedAt": "2026-06-21",
  "data": [
    {
      "id": "fraud_001",
      "title": "警惕冒充客服退款诈骗",
      "category": "冒充客服",
      "summary": "骗子冒充电商或快递客服，以退款、理赔为由诱导老人转账。",
      "detail": "诈骗分子通常会声称商品存在质量问题……",
      "risk": "可能造成银行卡信息泄露、验证码泄露或资金损失。",
      "advice": "退款应在官方购物平台内完成。\n不点击陌生链接。\n不向任何人提供验证码。",
      "sourceName": "公安部/国家反诈中心宣传内容整理",
      "sourceType": "official",
      "sourceDate": "2026-06-11"
    }
  ]
}
```

**旧版 JSON 完全兼容**：仅有 title/category/summary/detail/measures 时也能正常工作。所有字段使用 `optXxx` 安全读取，缺少时使用合理默认值。

## 五、每日推送实现

### 架构

```
SettingsFragment                    WorkManager
  "每日防诈提醒"开关                    │
    ├── 开启 ──→ 请求通知权限(13+)      ├── FraudReminderWorker
    │          注册周期任务 ────→        │     ├── 同步拉取远程 JSON
    │                                  │     ├── 成功 → 远程内容
    │                                  │     └── 失败 → 本地预置（按日期轮换）
    └── 关闭 ──→ 取消周期任务           │     └── 发送通知
                                       │
                                  NotificationManager
                                    └── "今日防诈提醒" 通知
                                          └── 点击 → FraudDetailActivity
```

### 关键常量

| 常量 | 值 | 用途 |
|------|-----|------|
| `FRAUD_REMINDER_WORK_NAME` | `"daily_fraud_reminder"` | WorkManager 任务名称 |
| `FRAUD_CHANNEL_ID` | `"fraud_reminder"` | 通知渠道 ID |
| `NOTIFICATION_ID_BASE` | `901` | 通知 ID |

### 生命周期

- **开启**：保存 SharedPreferences → 创建通知渠道 → 注册 24h 周期 WorkManager
- **关机重启**：`SilverGuardianApp.onCreate()` 和 `BootReceiver` 检查开关状态，自动恢复
- **关闭**：取消 WorkManager 周期任务 → 清除 SharedPreferences 标记

## 六、适老化设计要点

| 层面 | 设计 |
|------|------|
| 列表字体 | 使用项目 `SectionTitle` 样式（较大字号） |
| 卡片层级 | 标题 → 分类标签(Chip) → 摘要，层级清晰 |
| 详情分块 | 骗局简介 / 案例详情 / 风险说明 / 防范措施 / 内容来源 |
| 通知标题 | 固定"今日防诈提醒"，不制造恐慌 |
| 通知内容 | ≤80 字，格式："标题，摘要"，一目了然 |
| 通知渠道 | 关闭振动和铃声，避免惊吓老人 |
| 离线提示 | 列表分类标签显示"离线"badge；详情页顶部显示"当前为离线安全提醒内容" |
| 空态保护 | 远程加载失败不白屏，自动回退 SQLite 本地数据 |

## 七、数据来源说明

App 拉取的是人工整理后的统一 JSON 数据，而非直接爬取第三方网页（避免结构不稳定、字段不统一的问题）。

内容整理自以下权威渠道：
- 公安部 / 国家反诈中心
- 12321 网络不良与垃圾信息举报受理中心
- 中国互联网联合辟谣平台
- 国家金融监督管理总局（养老诈骗、金融风险提示）
- 96110、12381、国家反诈中心 App 等官方反诈工具科普
