# 银发守护者 Android 原型验收报告

## 验收目标

验证 Android 原生原型的交互流程与原始 Vue Web 应用的交互体验一致，所有核心功能可运行无崩溃。

---

## 一、登录模块（LoginActivity）

### 1.1 用户展示
- [ ] 打开 App，显示老人头像网格（爷爷、奶奶）
- [ ] 每个用户显示首字头像和姓名

### 1.2 用户选择
- [ ] 点击用户头像，头像高亮选中，顶部显示选中用户名
- [ ] 默认选中第一个用户

### 1.3 PIN 登录
- [ ] PIN 输入框限制 4 位数字
- [ ] 未满 4 位时"登录"按钮禁用（灰色）
- [ ] 输入 4 位后按钮变为可点击（蓝色）
- [ ] **重点：爷爷 PIN=`1234` 登录成功，跳转到 MainActivity**
- [ ] **重点：奶奶 PIN=`5678` 登录成功**
- [ ] 错误 PIN 时提示"PIN 码错误，请重试"，输入框清空

### 1.4 添加用户
- [ ] 点击"添加老人"弹出表单
- [ ] 填写姓名、PIN、年龄、健康状况 → 保存 → 出现在用户列表
- [ ] **重点：新用户输入正确 PIN 可登录**

### 1.5 删除用户
- [ ] 长按用户头像 → 确认弹窗 → 删除
- [ ] 只剩 1 个用户时提示"至少保留一个老人档案"

## 验收重点（优先级排序）

| 优先级 | 模块 | 为什么重点 |
|--------|------|-----------|
| **P0** | 登录→主页完整流程 | 整个 App 的入口，崩了就全完 |
| **P0** | AI 对话发送/回复 | 核心交互，含安全劝解规则 |
| **P0** | 用药打卡 | 核心功能，数据库写入验证 |
| **P1** | 多用户切换+数据隔离 | 验证 SQLite 数据按 userId 隔离 |
| **P1** | 相册上传+收藏 | CRUD 完整流程验证 |
| **P1** | 数据持久化 | 退出重登数据不丢失 |
| **P2** | 设置页各入口 | 不崩溃即可 |
| **P2** | 分页筛选 | 用户体验验证 |
| **P3** | 辅助页面 | ChildMode/Bluetooth/PhotoDetail |

## 验收方法

1. **手动走查**：按上述 Checklist 逐项操作
2. **Logcat 监控**：全程打开 Logcat 过滤 `com.silverguardian.prototype`，出现红色 Error 立即记录
3. **数据库验证**：在模拟器中用 Device File Explorer 找到 `/data/data/com.silverguardian.prototype/databases/elderly_guardian.db`，导出后用 SQLite 工具打开验证数据正确性
4. **多轮测试**：每个功能操作 3 次以上确认无偶发崩溃
